# ASCII 3D Cube Renderer

Вращающийся каркасный куб в консоли на Python. Без сторонних библиотек.

## Демо
![Демонстрация работы](docs/demo.gif)

## Запуск
python main.py

## Как работает
- 8 вершин и 12 рёбер
- поворот вокруг осей Y и X
- перспективная проекция
- рисование линий по алгоритму Брезенхема/интерполяции
